🧰 Câu 1 – Tạo products.xml
← Về cửa hàng

Đọc API bằng mô hình DOM → kiểm tra ảnh → bổ sung màu sắc, tồn kho → xuất products.xml

Các bước: (1) lấy JSON từ https://fakestoreapi.com/products; (2) kiểm tra từng link ảnh (nếu lỗi tự thử đổi đuôi .jpg ↔ t.png); (3) thêm màu sắc, kích cỡ, tồn kho; (4) dựng cây DOM XML, serialize và tải về. Lưu file vào data/products.xml (ghi đè).
