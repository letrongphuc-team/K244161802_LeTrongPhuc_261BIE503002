# MiniShop – Bài kiểm tra giữa kỳ Phát triển Web Kinh doanh (Mã đề BW08)
Sinh viên: **Lê Trọng Phúc** – MSSV **K244161802** – Lớp 261BIE503002

## Chạy
Mở thư mục bằng VS Code → chuột phải `index.html` → **Open with Live Server** (không mở trực tiếp file://, vì fetch bị chặn).

## Cấu trúc
- `index.html` – trang chủ (Câu 2–7) · `admin.html` – Admin (Câu 8) · `tools.html` – tạo products.xml từ API (Câu 1)
- `css/style.css` · `js/common.js, store.js, cart.js, checkout.js, admin.js`
- `data/` – products.xml, reviews.xml, carts.xml, employees.json, customers.json
- `testcase/` – ảnh chụp kết quả · `Test-Case-Result-K244161802.docx` – file test case

## Tài khoản demo
- Admin: `admin` / `admin123` (xem thêm data/employees.json)
- Khách hàng (điền nhanh khi thanh toán): data/customers.json

## Đưa lên GitHub Pages (Câu 9)
Tạo repo mới → đẩy toàn bộ nội dung thư mục này (index.html nằm ở gốc) → Settings → Pages → Branch `main`, folder `/ (root)` → Save.
